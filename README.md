# Mayank Singh Portfolio

This is my personal portfolio site.

## Deployment

This site is ready for GitHub Pages.

1. Create a repository named `MayankSingh6.github.io` (or any name you prefer).
2. Upload these files (`index.html` and `May_resume_AUG.pdf`) to the root of that repo.
3. Enable GitHub Pages in your repository settings (Settings → Pages → Source → `main` branch, root folder).
4. Your site will be live at `https://MayankSingh6.github.io/` (if repo is named that way).
